# Roadmap

Próximas features e melhorias planejadas.

## Curto Prazo (1-3 meses)

### Sprint 11: Gestão de Usuários Admin
- [ ] CRUD completo de usuários
- [ ] Alteração de senha
- [ ] Listagem e filtros

### Sprint 12: Revogação Manual de Tokens
- [ ] Logout (revogar tokens)
- [ ] Revogar todos os tokens de um usuário
- [ ] Listagem de sessões ativas

### Sprint 13: Auditoria e Logs Avançados
- [ ] Log de ações importantes
- [ ] Auditoria de mudanças
- [ ] Histórico de acessos

## Médio Prazo (3-6 meses)

### Features de Negócio

- [ ] Categorias de livros
- [ ] Busca avançada (full-text search)
- [ ] Avaliações e comentários
- [ ] Recomendações baseadas em comportamento
- [ ] Cupons de desconto
- [ ] Programa de fidelidade

### Melhorias Técnicas

- [ ] Cache com Redis
- [ ] Fila de mensagens (RabbitMQ/Kafka)
- [ ] Elasticsearch para busca
- [ ] Rate limiting
- [ ] Circuit breaker

## Longo Prazo (6-12 meses)

### Infraestrutura

- [ ] Migração para Kubernetes
- [ ] CI/CD completo
- [ ] Monitoramento com Prometheus + Grafana
- [ ] Logs centralizados (ELK Stack)

### Features Avançadas

- [ ] Multi-tenancy
- [ ] Internacionalização (i18n)
- [ ] PWA (Progressive Web App)
- [ ] App mobile

### Escalabilidade

- [ ] Microservices (se necessário)
- [ ] Database sharding
- [ ] CDN para imagens
- [ ] Load balancing

## Melhorias Contínuas

- Atualização de dependências
- Refatorações
- Otimizações de performance
- Melhoria de testes (cobertura 80%+)
- Documentação
